## 判定範圍

**已確認需處理的語意問題：** snapshot-only Unknown randomizer 的 synthetic bag 不是實際 SevenBag remainder，但 evaluator 仍透過它的大小給出「額外一次 T cutout」資源估计。這個特定供應依據不受目前資訊模型支持，不能當成已知可兌現攻擊。它影響的不只 T-slot bonus，還有基礎盤面風險。

**未證明：** 未來不會來 T、模板一定不可達、T-slot feature 無用、bot 的 top-1 因此選錯、修正一定變強。未知尾端的 T 可能具有殘值；有 T 的模板也不保證在期限內可兌現。單憑這些 witness 不應將所有 unknown-tail T 價值設零。

記錄的 selectedPath 是到某個 DAG state 的路徑，不是最終最佳 continuation。不能把局部 leaf 分數直接歸因為根節點排名原因。

## 接下來應處理的具體問題

不再為同一 phenomenon 擴大對戰或調 bonus。先把現有 T-slot 機制拆清楚：

1. 已公開可用 T 對模板的支持（仍須 timing/reachability 限制）。
2. 未知 tail 的潛在 T-slot 價值（策略估計，不能冒充 bag remainder）。
3. 假想消行替代真實盤面指標的額外效果。

在選修正方式前，對這批已保留 witness 做離線幾何可達性與前後 board 評分對照，先區分「模板幾何就不成立」和「成立但需要未揭露資源」。不直接改權重、刪整個機制或宣稱 promotion。其餘 feature 仍沿語意審查表處理，T-slot 是第一個取得動態證據的項目。
